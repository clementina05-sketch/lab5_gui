### Как запустить:
Каждый файл запускается отдельно (откроется графическое окно):

py task_2.py
py task_3.py
py task_4.py
py task_5.py

### Результаты выполнения:

**1. task_1.py (Вкладки):**
При запуске открывается окно с тремя вкладками. Пользователь может переключаться между ними.

**2. task_2.py (Меню):**
Открывается окно с верхним меню "File". При нажатии на "File" выпадает список, в котором есть пункт "Exit", закрывающий программу.

**3. task_3.py (Кнопка «Привет»):**
Открывается окно с кнопкой. При нажатии в консоль выводится "Привет!".

**4. task_4.py (Конвертер валют):**
Окно для ввода суммы в рублях. При нажатии на кнопку программа пересчитывает сумму в доллары по курсу (95 руб. = 1 USD).

**5. task_5.py (Несколько окон):**
Главное окно с кнопкой. При нажатии открывается второе окно, которое можно закрыть отдельно.
